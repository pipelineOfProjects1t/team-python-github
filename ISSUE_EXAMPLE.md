# Issue example

## Заголовок

Добавить проверку оценки от 1 до 5

## Описание

В проекте «Учёт посещённых мест» нужно добавить проверку пользовательского ввода и защиту от некорректных данных.
Это позволит сделать приложение надежнее и показать работу с GitHub Issues.

## Как закрыть Issue коммитом

```bash
git commit -m "Добавить проверку оценки от 1 до 5. Closes #1"
```

После пуша ветки на GitHub задача закроется автоматически, если номер Issue действительно равен `#1`.
